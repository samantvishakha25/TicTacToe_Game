# Tic Tac Toe Game 

## Introduction

Tic Tac Toe is a classic two-player game developed using Python and Tkinter. The application provides an interactive graphical interface where two players can enjoy the game on the same computer.

## Objective

The main goal of this project is to create a user-friendly Tic Tac Toe game while demonstrating Python programming concepts and graphical user interface development.

## Features

1. Two-player gameplay.
2. Player 1 uses **X**, and Player 2 uses **O**.
3. Automatic winner detection.
4. Highlighting of winning combinations.
5. Draw detection when the board is full.
6. Restart option to play again.
7. Interactive graphical interface.
8. Indicator showing whose turn it is.
9. Notifications when a player wins or the game ends in a draw.

## Technologies Used

1. Python 3
2. Jupyter Notebook
3. Tkinter

## Requirements

To run this project, you need:

1. Python 3.x installed on your computer.
2. Jupyter Notebook or JupyterLab.
3. Tkinter library.

## How to Run

1. Install Python 3.x on your system.
2. Install and open Jupyter Notebook or JupyterLab.
3. Open the `Tic_Tac_Toe.ipynb` notebook.
4. Execute the notebook cells in the correct order.
5. Wait for the graphical game window to appear.
6. Start playing by placing X on the game board.

## How to Play

1. Player 1 starts the game using X.
2. Player 2 takes the next turn using O.
3. Select an empty cell to place your symbol.
4. Continue taking turns until a player wins or the game ends in a draw.
5. A player wins by placing three matching symbols horizontally, vertically, or diagonally.
6. If all nine cells are filled without a winner, the game is declared a draw.
7. Click the **Restart** button to begin a new game.

## Game Interface

The application includes the following components:

1. A 3 × 3 interactive game board.
2. Current player and turn information.
3. X and O player symbols.
4. A Restart button.
5. Visual highlighting of winning combinations.
6. Result notifications for wins and draws.

## Project Structure

The project contains a Jupyter Notebook file with the game implementation.
